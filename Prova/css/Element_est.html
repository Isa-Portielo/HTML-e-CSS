Elementos de estilo:

Cores:

background-color:

Serve para colocar cor de fundo de determinada area,
seja de todo o body como também das div's.

Coloca-se neste formato + uma cor em inglês.

É necessário coloar ponto e virgula (;) para fechar o atributo.

color:

Serve para deterninar a cor das letras de
determinada area ou elemento.

Coloca-se no formato color: cor-ingles;

Outras formas de declarar cor neses elementos:

Formato rgb:

Significa Red, Green, Blue. Vermelho, verde e azul
em inglês respectivamente.

Pode ser usado da seguinte forma: color: rgb(0,0,0);

Coloca-se o sistema e, logo em seguida, entre parênteses
colocamos o valor para cada uma das cores, assim formando uma cor solida.

CSS colors:

Pesquisa-se um site e acha todos os nomes ou codigos de cada cor do css.

Coloca-se da forma normal, afinal é apenas uma pesquisa.

Ou, entre no link: css tabela de cores

Outros Elementos de estilo:

font-size: valorpx;

Usa-se para mudar tamanho da fonte.

text-decoration

Serve para sublinhar o que não é naturalmente sublinhado e para apagar
o sublinhado do que é naturalmente sublinhado (links por exemplo )

Quando não queremos sublinhado: tezt-decoration: none;

Quando queremos sublinhado: text-decoration: underline;

style:

Style: none;
Tira o estilo do elemento (usado para tirar os símbolos das listas).

height

Assim como no html, é utilizado como tamanho (altura), a unica coisa
diferente é que o valor se coloca em px.

width

Assim como no html, é utilizado como tamanho (largura), a unica coisa
diferente é que o valor se coloca em px.
