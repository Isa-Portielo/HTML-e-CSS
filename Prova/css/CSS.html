CSS

Cascading Style Sheets

CSS é uma liguagem para estilo, é possivel usa-la não só com
html mas também com outras linguagens de codigo.

Elementos atributos:

CSS possui elementos para dar estilo, mudar posição e
exposição da página. Estes são:

Elementos de estilo:

Elementos de cor, fundo, decoração, enfim...

Clique aqui para mais.

float

Flutuar. O que colocarmos float vai flutuar sempre mais acima do último
elemento e para o lado em que colocarmos (esquerda ou direita)

overflow

Utilizada para tratar conteudos que ultrapassam os limites de um elemento.
Objetivo, fazer com que conteudos muito grandes possam caber dentro da pagina
atraves do uso de barras de rolagem.
Usamos overflow: hidden; Para enquadrar o elemento filho no elemento pai que
declaramos e overflow:show;

display

Forma como o elemento é colocado na página.

Display: none;
Tira a aparição da tela.
Display: block;
Coloca a aparição.


:hover

Corresponde quando o usuario designa um elemento com um dispositivo
apontador, mas não necessariamente o ativa.

Para colocar comentário:

Coloca-se uma barra (/) e um asterisco (*), do outro lado a ordem ao contrário: /* */

Elementos de espaço:

Margem (margin), Espaço entre o conteudo e a borda (padding), e borda(border).
