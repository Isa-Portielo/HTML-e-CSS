Elementos de espaço:

boder

É a linha entre a margin e o padding

Assim como no html utiliza-se para borda (linha).

No css, o valor é dado em px, logo apos colocamos o formato e a cor.

formatos: solid para solida; dashed para tracejada.

Cor colocada com o nome inglês ou no formato rgb.

margin

Margem, a parte da borda de determinado local e o resto da pagina.

padding

Espaçamento interno. É o espaço entre a borda e o conteudo.

Como colocar valores:

Como numeros/ valores:

Um valor:

Vale para todos os lados.

2 valores:

O primeiro vale para cima e baixo e o segundo para direita e esquerda.

4 valores:

Cada um vale para um lado, indo em sentido horário: cima, direita, baixo, esquerda.

Forma específica:

top: ;

Para cima.

botton: ;

Para baixo.

left: ;

Esquerda.

right: ;

Direita.
