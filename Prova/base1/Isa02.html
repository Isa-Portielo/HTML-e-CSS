    Esta é uma explicação sobre HTML.

    O que é?

    HTML é um tipo de liguagem para construção de sites.
    Não é muito ultilizada porém, já que existem outras liguagens atualizadas no mundo da computação como: JS, C*, etc...

    Conteúdo:

    Nós estudamos esta liguagem nas aulas e aprendemos alguns elementos e atributos apesar da explicação de cada tipo não esteja aqui, temos os elementos basicos que também exigem uma certa atenção

    Elementos:

    Elemento HTML:

    Elemento que da o conteudo. É o que abre o codigo. Todo o codigo vai dentro dele então, dizemos que ele tem conteudo. Como há conteúdo, ele abre e fecha.

    Elemento head:

    Elemento para colocarmos metadados. Coloca-se o atributo meta e o atributo link dentro dele.

    Atributo meta:

    É um metadado, o que utilizamos que da-se com: "meta charset="utf-8", ajuda a mostrar na tela caracteres especiais como acentos e simbolos do teclado.

    Atributo link:

    Serve para ligar o codigo html com o css. Da-se como: "link rel="stylesheet" href="nome_da_pag.css"

    Elemento body:

    Conteudo, corpo da pagina. É o que aparece para o usuario.

    Atributo class:

    Uma classsificação para melhor identificação no codigo CSS

    Elemento a:

    Links.
    Coloca-se: "a href="nome_da_paglink.Nomedaliguagem"
    Pra google: "a href="https://www.google.com/search?q=oq+tu+Quer+pesquisar"
    pra Youtube: "a href="https://youtube.com/results?search_query=oq+tu+Quer+pesquisar"

    Elemento img:

    Elemento de imagem.
    Possui atributos como:
    src= "nome_da_imagem"
    height="numero" (tamanho, altura)
    width="numero" (tamanho, largura)

    Elemento p:

    Paragrafo.

    Elemento h:

    Titulos e Subtitulos.
    Vai do 1 até o 6. Quanto maior o numero, menor o tamanho da letra.

    Elemento div:

    Conteiner de bloco.
    Serve para colocar conteudo dentro e ajuda em classificações para CSS.

    Elemento span:

    Conteiner de linha. Faz a mesma coisa que a div, só que faz em linha em vez de bloco inteiro.

    Elemento br:

    Quebra a linha.
