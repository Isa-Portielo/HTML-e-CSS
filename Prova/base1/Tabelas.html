Está é uma explicação sobre tabelas.

A tabela é uma estrutura que utilizamos para organizar dados, que são informações sobre determinado assunto.

Elementos:

  1. table

    É a tabela em si.

    Para colocar borda: border="valor", ou colocar em css

  2. th

    Linha do cabeçalho

  3. td

    Linha da tabela
