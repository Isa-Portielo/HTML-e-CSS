Formularios

Formulários são textos com pedido de conteudo.
Se pede ao usuario para responder determinadas coisas.

Elementos basicos:

form.

É o elemento principal. Dá a abertura para o código.

label

É um tipo de rótulo. É o rotulo que se usa para dar um
norte para o usuario digitar, por fora da caixa.

Tipos:

No HTML possuimos varios tipos de formularios que são
separados em classificações chamadas types.

type=text

Esse é o formulario de digitação.

Elementos:

Elemento input

É o que dá corpo para esse tipo, funciona como uma caixinha para a digitação.

Atributo type=text
Dá o tipo do input e, obviamente vai dentro do input.
Atributo name=""

Um tipo de classificação para o input.

Atributo placeholder=""

Rótulo que se coloca dentro da caixa, como o label só que dentro.

Atributo autocomplete=""

Pode ser dado como on ou off, define =, como o proprio nome diz,
se ira ter ou não a possibilidade de auto completar para o usuario,
vendo as respostas anteriores salvas dele.

type=number

Esse é o tipo que determina o form numerico.

Elementos:

Elemento input

É o que dá corpo para esse tipo, funciona como uma caixinha para a digitação de numeros.

Atributo type=number
Dá o tipo do input e, obviamente vai dentro do input.
Atributo name=""

Um tipo de classificação para o input.

Atributo min

Da o valor minimo para se colocar.

Atributo max

Da o valor maximo para se colocar.

Atributo step

Da o valor para se pular.

type=file

Esse é o tipo que determina o form foto.

Elementos:

Elemento input

É o que dá corpo para esse tipo, funciona como uma caixinha para o arquivo da foto.

Atributo type=file
Dá o tipo do input e, obviamente vai dentro do input.
Atributo name=""

Um tipo de classificação para o input.

type=date

Esse é o tipo que determina o form data.

Elementos:

Elemento input

É o que dá corpo para esse tipo, funciona como uma caixinha para
digitação de data do tipo: dd/mm/aaaa .

Atributo type=date
Dá o tipo do input e, obviamente vai dentro do input.
Atributo name=""

Um tipo de classificação para o input.

type=radio

Esse é o tipo que determina o form de varias opções e uma escolha do
estilo clique bolinha.

Elementos:

Elemento input

É o que dá corpo para esse tipo, funciona como um bloco com varias opções
e bolinhas do lado para clicar.

Atributo type=radio
Dá o tipo do input e, obviamente vai dentro do input.
Atributo name=""

Um tipo de classificação para o input.

Atributo value=""

Dá o valor para aquela opção.

type=checkbox

Esse é o tipo que determina o form de varias opções e uma escolha do estilo
clique bolinha.

Elementos:

Elemento input

É o que dá corpo para esse tipo, funciona como um bloco com varias opções e
bolinhas do lado para clicar.

Atributo type=checkbox
Dá o tipo do input e, obviamente vai dentro do input.
Atributo name=""

Um tipo de classificação para o input. Coloca-se colchetes que abrem e fecham
para ser possivel marcar mais de uma opção

Atributo value=""

Dá o valor para aquela opção.

type=reset

Esse é o tipo que determina o form botão de apagar.

Elementos:

Elemento button

É o que dá corpo para esse tipo, funciona como uma caixinha para o clique de apagar.

Atributo type=reset
Dá o tipo do input e, obviamente vai dentro do button.

type=submit

Esse é o tipo que determina o form botão de apagar.

Elementos:

Elemento button

É o que dá corpo para esse tipo, funciona como uma caixinha para o clique de enviar.

Atributo type=submit
Dá o tipo do input e, obviamente vai dentro do button.
Atributo formaction=""

Um tipo de link para o button.

Forms que não possuem type:

Várias opções e uma escolha botão

Não possui input e nem type, é dado por outra estrutura.
Serve para escolher um opção dentre varias escolhas, só que em vez
de clique é dado em uma caixa de seleção

Elementos:

Elemento select

Da o corpo do form, é uma caixa de seleção.

Atributo name=""

Um tipo de classificação para o select. Coloca-se dentro do select.

Elemento option

Elemento de opção.

Atributo hidden

Classificação que se da para o option. Esta é uma opção invalida como
um "Selecione" apanas para rotular a caixa ate a pessoa escolher uma opção.

Atributo value=""

Classificação que se da para o option. Esta é uma opção valida.

Comentario

Elemento textarea

Da o corpo do form, é uma caixa de digitação.

Atributo name=""

Um tipo de classificação para a textarea. Coloca-se dentro da textarea.

Elemento maxlenght

Dá o numero maximo de caracteres para o usuario digitar.
